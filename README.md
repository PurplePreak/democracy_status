# Democracy Status

In progress, the others countries will be added.

🇫🇷 Un coup d'œil pour comprendre où en est la démocratie en France.

Inspiré des pages de statut des grands services en ligne (status pages), Democracy Status propose une visualisation simple et claire de l'état de la démocratie en France : un dashboard sur le modèle des statuts GitHub, avec 8 critères et 39 indicateurs — élections libres, séparation des pouvoirs, État de droit, justice indépendante, libertés fondamentales, presse pluraliste, transparence, protection des minorités — complétés par deux critères de vigilance (dérive autoritariste, fascisation).

## Factuel et sourcé, ou rien.

Ce projet a été réalisé avec l'assistance d'une IA, mais rien n'y est affirmé sans preuve :
 - Chaque indicateur est sourcé : texte de loi, décret, décision du Conseil constitutionnel, rapport institutionnel (CADA, CNIL, HATVP…), avec source et date de vérification.
 - Chaque statut est documenté : Actif, Inactif ou Instable, accompagné d'un commentaire court résumant la situation.

L'IA cherche, l'humain tranche. Les faits vérifiables sont documentés ; les arbitrages de seuil et les jugements politiques restent une décision humaine, lors de la mise à jour manuelle.

Si vous constatez une erreur ou une source manquante : c'est un bug, signalez-le.

## Participer

Ce projet est un effort de pédagogie démocratique ouvert. Vous pouvez contribuer :

## Signaler un statut erroné ou une source périmée (issue)

- Proposer une source plus récente ou un nouvel indicateur
- Aider à étendre le projet à d'autres pays
- En discuter, débattre, contester — c'est aussi ça, la démocratie

Toute contribution argumentée et sourcée est bienvenue.

## 🚀 Project Structure

Inside of your Astro project, you'll see the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src
│   ├── assets
│   │   └── astro.svg
│   ├── components
│   │   └── Welcome.astro
│   ├── layouts
│   │   └── Layout.astro
│   └── pages
│       └── index.astro
└── package.json
```

To learn more about the folder structure of an Astro project, refer to [our guide on project structure](https://docs.astro.build/en/basics/project-structure/).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `yarn install`             | Installs dependencies                            |
| `yarn dev`             | Starts local dev server at `localhost:4321`      |
| `yarn build`           | Build your production site to `./dist/`          |
| `yarn preview`         | Preview your build locally, before deploying     |
| `yarn astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `yarn astro -- --help` | Get help using the Astro CLI                     |
